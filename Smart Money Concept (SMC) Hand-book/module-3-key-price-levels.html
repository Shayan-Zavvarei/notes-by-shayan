Key Price Levels

The zones you actually enter from. Order blocks, breakers, rejection and propulsion blocks, fair value gaps, the imbalance family, and the PD array hierarchy that ranks them all.

3.1

Order Blocks — the institutional footprint

The last opposing candle before a structure-breaking move. Bullish OB = last red candle before an up-BOS; bearish OB = last green before a down-BOS. Toggle direction, then play the return-and-react.

OB / FVG zone bullish bearish entry
3.2

Breaker Blocks — a failed OB that flips

A breaker requires a sweep of a prior swing then a structure break the other way. The failed move's origin becomes support/resistance in the new direction. Step through the formation.

3.3

Rejection & Propulsion Blocks

Rejection block uses the long wick of a sweep-and-reject. Propulsion block is an OB sitting on prior orders that relaunches price. Order block (body) is your default. Compare all three.

3.4

Fair Value Gaps — the 3-candle imbalance

When candle 1's wick and candle 3's wick don't overlap, the gap between them is the FVG. The 50% line (consequent encroachment) is the precision entry. Step through formation, partial fill, full fill, and inverse.

3.5

Volume Imbalance & Void

FVG = wick-to-wick gap (clear daylight). Volume imbalance = body-to-body gap with wicks overlapping (thin slit). Void = extreme one-sided run. Priority for entry: FVG > VI > Void.

imbalance FVG = enter · VI = refine · Void = target
